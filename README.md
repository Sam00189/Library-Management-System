# Library Management System

A console-based Library Management System built in Core Java with JDBC and MySQL.

## Features
- Add books and members
- Issue and return books
- Fine calculation for late returns
- Multithreaded handling of concurrent book requests

## Tech Stack
- Java (OOP, Interfaces, Exception Handling, Multithreading)
- JDBC
- MySQL

## Setup
1. Create a MySQL database called library_db
2. Run the table creation SQL (books, members, transactions)
3. Update DataBaseConnection.java with your MySQL credentials
4. Run Main.java
